A beginner Python project that converts written numbers into integers.

Examples:
- twenty six -> 26
- four hundred -> 400
- three thousand -> 3000
- one hundred thousand -> 100000

Features:
- Convert numbers from one to ninety-nine
- Convert hundreds
- Convert thousands
- Convert millions
- Unknown word detection
- Quit command
